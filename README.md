# CPA Fire

Painel de gestão de ciclos, metas e fechamentos (CPA • Cassino • Bets).

**Acesse:** https://nitaellybarbosa.github.io/cpa-fire/

## Como funciona

- O site é um único arquivo (`index.html`), sem servidor.
- Os dados ficam salvos **no navegador de quem usa** (localStorage). Nada é enviado para este repositório.
- Para levar os dados para outro aparelho ou navegador, use **Backup dos dados** no menu lateral (baixar e restaurar o `.json`).

## Atualizar o site

Substitua o `index.html` por uma versão nova (Add file → Upload files → Commit changes). O GitHub Pages publica em cerca de 1 minuto e os dados salvos nos navegadores continuam lá.
